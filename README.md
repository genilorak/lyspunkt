# Lyspunkt

**Et lysere blikk på verden.**

Designforslag for Lyspunkt, en norsk nettavis med positive nyheter, gode historier og dokumenterte fremskritt.

## Innhold

| Mappe | Hva |
|---|---|
| `index.html` | Oversikt med lenker til alle sidene |
| `sider/` | Hver tavle som en vanlig HTML-side som kan åpnes i nettleseren |
| `design/` | Kildefilene fra Claude Design-lerretet (`.dc.html` og `canvas.json`) |
| `bilder/` | Bildene som er brukt i forslagene |

## Designretninger

1. **Nordic Optimism:** moodboard for visuell identitet og forside (`1`, `2`)
2. **Story-optimisme:** moodboard og story-skjermer for mobil (`3`, `4`)
3. **Nettavis med story-energi:** desktop og mobil (`5`, `6`)
4. **Ung, levende nettavis:** gjeldende retning, desktop og mobil (`7`, `8`)

## Viktig

- Alle saker er **demoartikler, ikke faktiske nyheter**. Navn i [klammer] fylles inn senere.
- Bildene er illustrasjonsfoto fra [Unsplash](https://unsplash.com), brukt under Unsplash-lisensen. Fotografenes navn må legges inn før publisering.
- Skrifter: Bricolage Grotesque, Instrument Serif, Hanken Grotesk, Newsreader (Google Fonts).

## Se sidene

Åpne `index.html` i nettleseren. Du kan også slå på GitHub Pages under *Settings → Pages* for å få en lenke du kan dele.
